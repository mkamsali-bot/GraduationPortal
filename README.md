# Graduation Admit Card Portal

A Flask-based web application developed for GITAM (Deemed to be University) to generate Graduation Ceremony Admit Cards.

## Features

- Search using Registration Number
- Excel-based student database
- Dynamic admit card generation
- Institute-wise venue allocation
- Parent/Accompanying Guest venue display
- Print-friendly admit card

## Technologies Used

- Python
- Flask
- Pandas
- OpenPyXL
- Bootstrap 5
